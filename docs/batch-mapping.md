# ทำหลาย Effect และแก้ไฟล์เดิม

ใช้หน้าหลักหน้าเดียวใน `release/app/ResourceManager.App.exe` หรือเปิดผ่าน `เปิดโปรแกรม.cmd` แท็บเฉพาะ Texture และแท็บขั้นสูงถูกนำออกแล้ว

ระบบค้นทุกชนิดจาก path ใน Effect เสมอ ได้แก่ Texture, Material, Model/GLB, Sound และ Curve รวม Texture ภายใน Material ไม่มี checkbox จำกัดการค้นหา ดูชนิดไฟล์และข้อจำกัดใน [full-resource-repair.md](full-resource-repair.md)

การตรวจอย่างเดียวอยู่ในปุ่ม **ตรวจสอบอย่างเดียว** ของขั้นเลือกไฟล์ ไม่ต้องเลือกคลังและไม่เปลี่ยนไฟล์ ผลตรวจอยู่ในส่วนพับ **รายละเอียดผลตรวจ** ด้านล่าง มีขอบเขตผลตรวจ กรองชื่อ/สถานะ รายละเอียด path และการค้นไฟล์ที่ขาดในคลัง เปิด `.efkmat`, `.efkmodel` และ `.glb` แยกเพื่อตรวจได้ ผล audit หลัง Map ก็แสดงในส่วนเดียวกัน

## ขั้นตอน

1. เลือกไฟล์ `.efkefc` หรือโฟลเดอร์ ระบบค้น Effect ในโฟลเดอร์ย่อยด้วย
2. เลือกคลัง Asset ระบบค้นชื่อไฟล์พร้อมนามสกุลตรงกันในโฟลเดอร์ย่อย
3. ตั้งชื่อเรียกแล้วกด **บันทึกคลัง** เพื่อเลือกคลังนี้ครั้งหน้า การเอาออกจากรายการไม่ลบไฟล์
4. เลือก **ใช้ไฟล์ที่มีอยู่** เพื่อแก้ path ใน Effect เดิม หรือ **สร้างชุดใหม่** เพื่อรวบรวมสำเนา Effect/Asset
5. โหมดสร้างชุดใหม่เลือกปลายทางและชื่อโฟลเดอร์ Texture ได้ รวมตัวเลือกเปลี่ยนชื่อ Texture ส่วนโหมดใช้ไฟล์เดิมคงชื่อทุกไฟล์
6. กด **ค้นหา Effect และ Asset** เลือก Effect ที่ต้องการทำ แล้วดู Asset ของแต่ละ Effect พร้อมชนิด เจ้าของ และตำแหน่งจริง
7. หากชื่อซ้ำหลายที่และ path เดิมไม่ได้ระบุไฟล์ที่มีอยู่จริง ให้เลือกไฟล์จาก dropdown ของแต่ละกรณี
8. กด **ตรวจตัวอย่างทั้งหมดที่เลือก** ตรวจ path ผลลัพธ์ สำรอง และรายการที่ยังไม่ครบ แล้วกดบันทึก
9. เมื่อเสร็จ กด **เปิดตำแหน่งผลลัพธ์ของแถวที่เลือก** และเปิด Effect ใน Effekseer เพื่อตรวจภาพ

Effect ที่ไม่รองรับจะแสดงเหตุผลแยก หากบาง Effect ยังจับคู่ไม่ครบ เอาเครื่องหมายเลือกออกแล้วตรวจตัวอย่างใหม่เพื่อทำไฟล์ที่พร้อมก่อนได้

## ใช้ไฟล์ที่มีอยู่

แก้ Effect เดิมให้เรียก Asset จากคลังโดยตรงทุกชนิด รวม `.efkmat` และ `.glb` ไม่มีสำเนา Asset หรือโฟลเดอร์ `.resources-*` และไม่แก้ Material ในคลัง ต้องเก็บคลังไว้ที่เดิม

Texture ภายใน Material ตรวจตาม path ของ Material เดิม หากหาไม่เจอ หรือเลือกไฟล์ที่ Material เดิมไม่ได้อ้าง จะหยุดและแจ้งให้แก้ Material ก่อน หรือเลือก **สร้างชุดใหม่** เพื่อแก้ในสำเนา

ก่อนแทนที่ตรวจแฮช Effect และ Asset เทียบตัวอย่าง สำรองเป็น `fire.efkefc.backup-<id>.bak` และบันทึกการ Map เป็น `fire.efkefc.mapping-<id>.json` ข้าง Effect ทุกครั้งใช้ชื่อใหม่

การคืนค่า: ปิด Effect ใน Effekseer เก็บสำเนาเวอร์ชันปัจจุบัน แล้วคัดลอก `.bak` กลับเป็นชื่อ `.efkefc` เดิม ยังไม่มีปุ่ม Undo หลายขั้น

## สร้างชุดใหม่

Input มี `A/fire.efkefc` และ `B/fire.efkefc` จะได้ `A/fire.assets/` และ `B/fire.assets/` ภายใน output root ที่เลือก แต่ละชุดมี Effect, บันทึกการ Map และโฟลเดอร์ `Textures`, `Materials`, `Models` รวม `Sounds`/`Curves` เมื่อใช้ทรัพยากรชนิดนั้น

คัดลอก Asset และแก้ path ใน Effect/สำเนา Material ให้เรียกภายในชุดใหม่ Model/GLB คงชื่อและข้อมูลไบต์เดิม ไม่ทับโฟลเดอร์ผลลัพธ์เก่า หาก output root อยู่ภายใน input จะข้ามโฟลเดอร์ผลลัพธ์นั้นขณะค้น

## ใช้ชุดที่เคยสร้างเพื่อ Map ใหม่

โหมด **ใช้ไฟล์ที่มีอยู่** ไม่ใช้ค่าโฟลเดอร์ผลลัพธ์เดิมเป็นโฟลเดอร์ที่ต้องข้าม เลือก Effect หรือทั้งโฟลเดอร์ชุดเก่า และเลือกคลังที่มี Asset จริงได้เลย หากย้าย `Textures`/`Materials`/`Models` ไปอีกระดับ path เดิมใน Effect อาจหาไม่เจอ แต่การค้นชื่อไฟล์ในคลังจะพบและ Map ใหม่ได้

โหมดสร้างชุดใหม่ยังข้าม output ที่เป็นโฟลเดอร์ย่อยเมื่อค้นแบบกว้าง แต่เมื่อเลือก Input หรือคลังอยู่ภายใน output เก่าโดยตรง จะค้นขอบเขตที่เลือกตามปกติ ไม่ข้ามขอบเขตนั้นทั้งหมด

ตัวอย่าง `newmega/mega.assets/mega.efkefc` และ Asset อยู่ใน `newmega/mega.assets/mega/Textures`, `Materials`, `Models`: เลือกคลัง `newmega/mega.assets/mega` เพื่อค้นครบทุกชนิด ไม่จำกัดเฉพาะ `Textures`

## กรณีชื่อซ้ำและไฟล์หาย

- ชื่อ Asset ซ้ำ: เลือกจาก path จริงของแต่ละกรณี
- Texture ต่างข้อมูลแต่ชื่อปลายทางเดียวกันในชุดใหม่: หยุด ให้ตั้งชื่อต่างกันด้วยตัวเลือกเปลี่ยนชื่อ
- Texture ปลายทางเดียวกันและข้อมูลเหมือนกัน: คัดลอกครั้งเดียวหลังตรวจแฮช
- Effect ชื่อเดียวกันคนละโฟลเดอร์: แยกชุดตามโครงสร้าง input
- Asset ที่จำเป็นหาย: เพิ่มไฟล์/เปลี่ยนคลังแล้วค้นใหม่ หรือไม่เลือก Effect นั้น
- รายการเฉพาะ Editor ที่ไม่พบ: คง path เดิมพร้อมแจ้งเตือน

## คลังและการตรวจ

ชื่อคลังและ output root ล่าสุดเก็บที่ `%LOCALAPPDATA%/EffekseerResourceManager/settings.json` เก็บเฉพาะชื่อ/path ไม่มีการคัดลอก Asset เข้าการตั้งค่า

ทำดัชนีชื่อไฟล์ครั้งเดียวต่อการค้น batch ตรวจ SHA-256 ก่อนบันทึก ไม่ค้นนอกคลังที่เลือกและไม่ตาม symlink/junction แต่ละ Effect เป็นงานแยก งานก่อนหน้าที่สำเร็จจะยังอยู่หากงานถัดไปล้มเหลว งานปัจจุบันพยายามย้อนกลับเฉพาะไฟล์ที่งานสร้างและยังมีแฮชเดิม ถ้าไฟล์เปลี่ยนโดยโปรแกรมอื่นจะเก็บไว้พร้อม `Recovery required` ยังไม่มีการกู้คืนอัตโนมัติหลังไฟดับ

รองรับกลุ่ม stable 1.60–1.62, 1.70 และ 1.80 ตาม [version-support.md](version-support.md) การตรวจ path และโครงสร้างยังไม่ใช่การรับรองภาพผ่าน Effekseer Editor/runtime

ผ่าน 98 automated tests รวม Mega จริง ใช้ Asset เดิมทุกชนิดโดยไม่มีโฟลเดอร์เพิ่ม หยุดเมื่อ Texture ภายใน Material เสีย สร้างชุดใหม่แล้วเลื่อนโฟลเดอร์ Asset จากนั้น Map ใหม่โดยใช้ output เก่าเป็น Input/คลัง สำรอง/คืนค่าหลังยกเลิก และการคง shader/GUID/geometry/node data
