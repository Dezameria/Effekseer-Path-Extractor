# ไฟล์ไหนใช้ทำอะไร

## เปิดใช้งาน

ดับเบิลคลิก **เปิดโปรแกรม.cmd** ที่หน้าโฟลเดอร์ หรือเปิด **release/app/ResourceManager.App.exe** โดยตรง

ตัวโปรแกรมรวมไฟล์ประกอบไว้ใน EXE แล้ว ไม่ต้องติดตั้ง .NET เพิ่ม หากจะนำไปใช้เครื่องอื่น ให้คัดลอกโฟลเดอร์ **release** ไปด้วย

## โฟลเดอร์หลัก

| โฟลเดอร์ | เนื้อหา |
|---|---|
| `release` | โปรแกรมล่าสุดสำหรับใช้งาน: `app` เป็นหน้าจอโปรแกรม, `inspector` เป็นเครื่องมือสำหรับบรรทัดคำสั่ง |
| `effekseer` | Effect และ Texture ต้นฉบับที่ใช้ทดสอบ |
| `docs` | คู่มือ แผนพัฒนา และรายละเอียดรูปแบบไฟล์ |
| `src` | ซอร์สโค้ดของระบบ |
| `tests` | ชุดทดสอบ |
| `scripts` | ตัวช่วยสร้างโปรแกรม |
| `artifacts` | ผลทดสอบ ภาพหน้าจอ และตัวอย่างที่สร้างระหว่างพัฒนา |
| `artifacts/archive` | โปรแกรมรุ่นก่อนและไฟล์ที่สร้างระหว่างพัฒนา เก็บสำรองแยกโฟลเดอร์ |
| `.tools` | เครื่องมือ .NET สำหรับพัฒนาและสร้างโปรแกรมใหม่ |
| `.research` | ข้อมูลต้นทางที่ใช้ศึกษารูปแบบ Effekseer |

ไฟล์ `.sln`, `.props`, `global.json` และ `.gitignore` ที่หน้าโฟลเดอร์เป็นการตั้งค่าของโปรเจกต์

## สร้างโปรแกรมใหม่

ใช้ `scripts/build.ps1 -Publish` เพื่อสร้าง ทดสอบ และออกโปรแกรมแบบ EXE รวมไฟล์ไปยัง `release` ผลทดสอบอยู่ใน `artifacts/tests`

โฟลเดอร์ `bin` และ `obj` ภายใน `src` และ `tests` เป็นไฟล์ที่สร้างระหว่างพัฒนา สร้างใหม่ได้จากซอร์สโค้ด เมื่อสร้างโปรแกรมเสร็จสามารถย้ายเก็บสำรองด้วย `scripts/clean-build.ps1`

การจัดระเบียบวันที่ 7 ตุลาคม 2026 เก็บรุ่นก่อนและไฟล์ที่สร้างระหว่างพัฒนาไว้ใน `artifacts/archive/2026-10-07` รายการตำแหน่งก่อนและหลังย้ายอยู่ใน `moved-files.json` ภายในโฟลเดอร์นั้น หากต้องการใช้โปรแกรมเก่า เปิด EXE จากโฟลเดอร์สำรองได้โดยตรง
